# Customer Churn Prediction

## Internship Task

This project was developed as part of the CodSoft Machine Learning Internship.

## Objective

The objective of this project is to build a machine learning model that predicts whether a customer is likely to churn based on historical customer information.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models

Three classification models were trained and compared:

1. Logistic Regression
2. Random Forest
3. Gradient Boosting

## Approach

1. Loaded and inspected the customer dataset
2. Removed unnecessary columns and duplicate records
3. Analyzed customer churn distribution
4. Encoded categorical features
5. Split the data into training and testing sets
6. Trained three machine learning models
7. Compared model performance using accuracy, precision, recall and F1-score
8. Selected the best-performing model based on F1-score
9. Evaluated the final model using a classification report and confusion matrix
10. Tested the model on a sample customer
11. Saved the final trained model

## Final Model

Gradient Boosting was selected as the final model based on its F1-score among the models evaluated.

- `customer_churn_model.pkl` — Trained Gradient Boosting model
